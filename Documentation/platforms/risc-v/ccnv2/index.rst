===============
ChipCraft CCNV2
===============

.. warning::

  Implementation of this chip is still experimental and work in progress :-)

CCNV2 is ChipCraft's [chipcraft] NaviSoc [navisoc] series MCU eqipped with
5 core RISC-V CPU, standard peripherals, and the custom radio for GNSS
centimeter accuracy satellite positioning signals processing.
